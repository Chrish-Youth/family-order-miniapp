\# 家庭点菜微信小程序



\## 项目介绍



这是一个基于微信小程序原生框架开发的家庭点菜项目，主要用于家庭内部点菜、菜品展示和订单记录。项目包含首页推荐、菜品分类、购物车、订单页面等核心模块，具备完整的小程序页面结构和基础业务闭环。



\## 技术栈



\- 微信小程序原生框架

\- WXML

\- WXSS

\- JavaScript

\- JSON

\- 微信开发者工具



\## 核心功能



\- 首页推荐菜展示

\- 菜品分类浏览

\- 商品数量加减

\- 购物车弹窗

\- 商品价格自动计算

\- 订单页面展示

\- 底部导航栏

\- 真机预览与调试



\## 项目亮点



\- 使用 JavaScript 管理商品状态、购物车数量和价格计算逻辑

\- 实现从首页推荐菜直接加入购物车，减少用户操作路径

\- 完成购物车弹窗、商品加减、订单展示等常见业务交互

\- 独立完成页面布局、样式调整、功能调试和真机预览

\- 项目结构清晰，包含 pages、components、utils、assets 等模块
