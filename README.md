# 家庭点菜微信小程序

一个基于微信小程序原生框架开发的家庭点菜项目，提供菜品分类、购物车、订单确认、订单记录和个人统计等功能。

## 功能

- 分类浏览菜品并调整数量
- 首页与购物车合并的点餐流程
- 购物车弹窗、金额统计和订单确认
- 本地订单缓存
- 可选的微信云开发订单同步
- 订单记录和个人统计页面

## 技术栈

- 微信小程序原生框架
- WXML / WXSS
- JavaScript
- 微信云开发数据库（可选）

## 本地运行

1. 克隆仓库。
2. 使用微信开发者工具导入项目目录。
3. 确认 `project.config.json` 中的 AppID 可以使用，或替换成自己的 AppID。
4. 编译并在模拟器或真机中预览。

未配置云开发环境时，项目会自动使用本地缓存保存订单。

## 云开发配置

1. 在微信开发者工具中开通云开发并创建环境。
2. 在云数据库中新建 `orders` 集合。
3. 将环境 ID 填入 `config/cloud.js` 的 `envId`。
4. 配置数据库权限，确保用户只能读写自己有权访问的订单。

云端不可用时，订单会回退到本地存储，并在提交时提示“已保存到本机”。

```text
├── utils           # 数据存储工具
├── app.js

├── app.wxss
├── project.config.json
└── sitemap.json
```

## 上线前检查

- 填写正确的云环境 ID，并验证 `orders` 集合权限。
- 完整测试点菜、清空购物车、提交订单和清空订单流程。
- 确认图片、角色名称和其他视觉素材拥有合法使用授权。
- 根据仓库发布方式补充合适的开源许可证。
